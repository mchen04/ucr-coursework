Start with a course README, then change into the linked assignment directory. C++ assignments are independent programs and must not be linked together. Python assignment CLIs use their project directory for data lookup. No shared runtime or new collection-wide test suite is imposed.

The local BIO/BUS/CS166 notes are snapshots of academic summaries found on mbp-main under `~/Projects/Archive/vault-backup-2026-05-11/projects/school/`. They retain original frontmatter and wiki links. They are not copies of every paper/reading or `Research/`/`Reserach_Container/` artifact mentioned inside them. New course indexes provide ordinary Markdown links; historical wiki links to the surrounding vault may remain unresolved. See the [original coursework map](docs/local-coursework-map.original.md).

## Preservation and privacy

Keep this repository **private**. The current tree excludes compiled output, caches and nonacademic home artifacts. Exact unfiltered source history is retained through the history anchor and `source-history/*` branches. CS010B's old history contains home-directory/editor/auth-like paths identified only by metadata; their contents were not opened or scanned and may contain accidental sensitive material. Removing them from the current tree does not remove them from Git history. This archive is not safe for public redistribution.

[Sources and attribution](ATTRIBUTION.md), [complete path/blob manifest](SOURCES.json), [omission reasons](docs/OMISSIONS.md), [inventory decisions](docs/INVENTORY.md), [workflow results and limits](docs/VALIDATION.md), and [history/recovery guidance](docs/HISTORY.md) record the migration. Original repositories/checkouts remain untouched. GitHub conversations, settings and old link identities are not migrated. No blanket license or dataset/media ownership claim is added.
